## Review and publish

1. Verify publisher, release/checkpoint, code and weight licenses against the original model card.
2. Add a distinct entry for a new release; record sources and actual review date. Never reuse older audio as a new model sample.
3. Add setup, strengths, limitations, and explicit unknowns for unverified measurements.
4. Generate the three scripts where a suitable licensed provider is available; otherwise label samples pending.
5. Run npm run check:catalog, npm test, npm run lint, and npm run build.
6. Merge the reviewed catalog change and deploy.
