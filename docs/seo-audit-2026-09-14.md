# SEO audit — September 14, 2026

Search Console property: `sc-domain:openspeech.dev`. Reporting window: August 15–September 11 (28 complete days); previous window: July 18–August 14.

Google Search produced only **4 clicks** across the returned pages. The homepage had 924 impressions and 4 clicks, compared with 467 impressions and 4 clicks in the previous window. Two visible query-level clicks were for the brand “openspeech”; low-volume query reporting can omit anonymized searches. The generic “open source text to speech” query had 48 impressions, no clicks, and average position 69.2.

The existing analytics estimate of 105 organic-attributed visitors is not interchangeable with Google Search Console clicks. It uses a different attribution system, date range, and scope. The evidence does not support calling search acquisition strong yet.
